# ErgoLab : simulation ergonomique d’une cuisine scolaire

Projet Godot 4 (GDScript), destiné à une publication Web sur Vercel.

Le code source du prototype est disponible dans l’archive fournie dans la conversation. Ce dépôt est en préparation : **le simulateur n’est pas encore publié ni validé par une compilation Godot**.

## Objectif

Reconstituer le plan de la cuisine de la page 5 du sujet de TP, manipuler le matériel de la page 6, comparer des aménagements et déplacer des avatars afin d'étudier les circulations et les contraintes de travail.

## État

Le prototype local fournit le plan source comme fond, des équipements mobiles, deux scénarios de départ, des avatars, un tracé de déplacements et des observations sauvegardées dans le navigateur. La collaboration multi-utilisateur en temps réel sera une évolution distincte.

## Déploiement prévu

Compilation automatique Godot 4.4.1 en export Web via GitHub Actions, génération d'un dossier `docs/`, publication de ce dossier sur Vercel.
